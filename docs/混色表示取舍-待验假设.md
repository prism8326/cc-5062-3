# 混色表示取舍：待验假设清单

本文件只登记**尚未用真实颜料或用户实验验证**的假设。它们可以驱动当前原型结构，但不能在界面、实验结论或导出报告中被表述为实测事实。

## H1. 人工 K/S 参数只验证机制，不验证品牌颜料

- **假设**：`js/pigments.js` 中高斯吸收带、吸收边和散射基线足以产生方向合理的色相、罩染和同色异谱现象。
- **当前证据**：代码可复算厚度收敛、KM 能量范围、顺序差异和合成同色异颜料匹配。
- **尚未验证**：任何真实品牌色料的色相、着色力、透明度、染色性或 K/S 曲线。
- **验收/证伪方式**：接入实测光谱或品牌颜料数据库后，替换参数集 ID，重跑 `npm run experiments`，比较光谱 RMSE 与各色光源 ΔE00。

## H2. 7 箱受限参数模型的误差可用于交互预览

- **假设**：把 31 波段 K/S 压缩为 7 个非负箱均值，再在线性反射率域插值，能以可接受色差换取更低参数/内存成本。
- **当前证据**：`tools/out/pigment-model-experiments.json` 记录了每个试混片、互补对和深色配方的 ΔE00/RMSE；参数总量从 620 降到 140。
- **尚未验证**：箱数量、箱边界和插值方式对真实颜料陡吸收边是否稳定；当前微基准也没有证明受限模型一定更快。
- **验收/证伪方式**：以 ΔE00 阈值（例如交互预览 < 2、证据导出 < 1）扫描 3/5/7/10 箱和不同箱边界。

## H3. 质量域作为唯一物质事实可以避免双写漂移

- **假设**：画笔、湿膜、干层、封存和水洗都修改质量向量，光学层只做单向派生，比同时维护“光学参数层”和“物质层”更可靠。
- **当前证据**：Node 测试中反复分盘混合的相对质量漂移约为 `1e-15`；浏览器自检逐像素比较渲染缓冲与内核显示变换。
- **代价**：每次渲染都要从质量数组重建 `filmDepths`，大画布上的 CPU 成本较高。
- **尚未验证**：400×300 以上画布、更多干层或更高刷新率下的性能；增量缓存光学映射是否值得其失效复杂度。

## H4. 封存层是理想透明隔离层

- **假设**：封存后形成无颜料、无 K/S 响应但能阻止水到达下层的隔离层；它不改变颜色，只改变清水的物质可达性。
- **当前证据**：封存后水洗移除质量为 0，未封存可溶层按固定比例减少，总质量守恒。
- **尚未验证**：真实定画液、清漆或胶层的厚度、折射率、半渗透性和水洗时间效应。
- **验收/证伪方式**：加入真实封层 S/K、水溶渗透率和时间参数，并做物理试片称重/反射率测量。

## H5. 清水回取比例是经验线性政策

- **假设**：同一滴清水对未封存可溶层一次移除 `lift = 0.72` 的可回取质量；耐水结合剂移除比例为 0。
- **当前证据**：该政策可明确区分封存前/后，并通过质量账本导出剩余颜料量。
- **尚未验证**：水量、纸张湿度、颜料染色性、接触时间、笔压和颗粒沉淀的非线性影响。
- **验收/证伪方式**：把 `staining`、水量和时间接入传递系数，并用真实水洗废液或称重数据校准。

## H6. 昏暗照明用 A 光源加 45% 曝光足以暴露同色异谱

- **假设**：明亮 D65 与昏暗暖 A/45% 曝光是有效的展示条件，且独立显示变换能保留光源光谱差异。
- **当前证据**：合成底层在 D65 下 ΔE00 约 0.29，在暖 A 适应色度下约 3.39；导出 JSON 同时保存 Hex、Lab 和光谱。
- **尚未验证**：真实灯箱、观察者适应、背景明度和暗视觉/中等视觉效应。
- **验收/证伪方式**：加入实测光源 SPD、背景/眩光模型和观察者实验。

## H7. 密度—体积—覆盖厚度映射仍是原型尺度

- **假设**：当前用 `h = 颜料质量 + 载体体积` 的原型单位和固定 `BINDER_SOLID_FRACTION` 已足够表达浓度、厚度和晾干。
- **当前证据**：厚度梯度和保存往返颜色一致。
- **缺口**：`PIGMENTS[].density` 已声明但尚未完整参与质量→体积换算；真实颜料的吸油量、体积浓度和成膜收缩未建模。
- **验收/证伪方式**：把密度、吸油量和 CPVC 纳入 `m → volume → h` 映射，再重跑厚度/黑白底遮盖实验。

## H8. 浏览器像素一致只证明显示链路接通，不证明物理准确

- **假设**：`#view` 的 ImageData 与 `evaluatePixelColor()` 一致，说明绘画窗口确实使用了内核，而不是另一套 RGB UI 状态。
- **当前证据**：`绘画接点自检` 和 `node tools/browser-smoke.mjs` 读取真实画布像素。
- **边界**：像素一致性不能证明 K/S 参数、光源或水洗政策符合真实材料；后者仍受 H1–H7 约束。
